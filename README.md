# Twigg examples

Small, runnable apps built on the [Twigg](https://twigg.ai) API. Each one is a
single file with no SDK: just HTTP calls to `https://api.twigg.ai`.

| Example         | What it is                                                    |
| --------------- | ------------------------------------------------------------- |
| [chat](chat/)   | A streaming, multi-user chatbot for the terminal. JavaScript and Python. |

You need a Twigg API key. Get one at [twigg.ai](https://twigg.ai).
